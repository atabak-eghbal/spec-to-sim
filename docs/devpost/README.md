# Devpost drafts

One file per form section, written as we build so nothing is rushed at the end.

- `overview.md` — project name, elevator pitch, thumbnail idea
- `story.md` — About the project (Inspiration, What it does, How we built it, Challenges, What we learned, What's next)
- `additional-info.md` — track, Tavily, country/province, AI tools used, learning, career value
- `feedback.md` — answers to all Nemotron / Nebius feedback questions (aim for "Most Valuable Feedback")
- `video-script.md` — shot list and narration, ≤ 2:45
